🖨️ Anleitung zum PDF-Export für die Akten

  1. Öffnen Sie das gewünschte Dokument über die Schaltfläche „Öffnen“.
  2. Klicken Sie oben rechts auf die Schaltfläche „🖨️ Drucken / PDF“ (oder drücken Sie Strg + P bzw. Cmd + P).
  3. Wählen Sie im Druckdialog Ihres Browsers als Ziel „Als PDF speichern“ aus.
  4. Die Kopf- und Navigationszeilen werden im Druckmodus automatisch ausgeblendet; das Layout formatiert sich exakt auf DIN-A4 mit sauberen Seitenumbrüchen.
